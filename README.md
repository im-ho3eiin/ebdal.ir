# ایدال — نمونه اولیه

React + Vite + Tailwind v4 + Three.js (بدون بک‌اند)

## اجرا
نیازمند Node.js نسخه ۲۰.۱۹ یا بالاتر

```
npm install
npm run dev
```

سپس آدرس نمایش‌داده‌شده را در مرورگر (یا از موبایل در همان شبکه) باز کنید.

## ساختار
- `src/components/PipeScene.jsx` — شیر و لوله سه‌بعدی که با اسکرول می‌چرخد
- `src/components/` — Navbar, Hero, Services, Shop, Contact, CartDrawer
- `src/data.js` — خدمات و محصولات نمونه
- رنگ‌ها و فونت در `src/index.css` (بخش `@theme`)
